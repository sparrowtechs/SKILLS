# Contributing

Thanks for wanting to improve this repo.

The best contributions here are concrete and opinionated.

## Good Contributions

- tighten unclear wording
- improve structure without adding bloat
- add a new skill area with a clear main guide
- add a supporting guide that deepens an existing skill
- fix places where the guidance is too vague, too generic, or too repetitive

## What To Avoid

- generic AI-style filler
- adding content just to make a skill look bigger
- framework-specific advice in files meant to stay general
- checklist bloat without a clear guiding idea

## Preferred Shape

For a top-level skill, prefer:

1. `Purpose`
2. `Use This When`
3. `Modes`
4. `Core Principles`
5. `Supporting Guides`
6. `Output Format`

For supporting guides, prefer:

1. `Purpose`
2. `Use This When`
3. `Core Rules`
4. `Review Areas`
5. `Output Format`

## Contribution Style

- keep wording concrete
- prefer judgment over buzzwords
- preserve the repo's guide-first style
- make additions easy to scan and easy to reuse

If you open a PR, explain:

- what problem you saw
- what you changed
- why the repo is better after the change
