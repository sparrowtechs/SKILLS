# SKILLS

Guide-first skills for product, backend, and security work.

This repo is for people who want sharper guidance than generic best-practices lists or bloated AI output. The goal is to make good decisions faster with skills that are opinionated, practical, and reusable.

## What This Repo Is

This repository collects structured skills for:

- product and UI direction
- backend engineering and architecture
- security and release hardening

Each skill is designed to be:

- guide-first, not fluff-first
- concrete, not vague
- opinionated, not dogmatic
- useful in real delivery work, not just theory

## How To Use This Repo

1. Pick the skill that matches the problem area.
2. Read the main guide in that folder first.
3. Use the supporting guides when you need deeper direction on one surface.
4. Adapt the guidance to your product, stack, and team instead of applying it mechanically.
